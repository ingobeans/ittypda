# ittyOS

hiya! this folder contains the code for the shared operating system. 

the `../firmware` folder contains the low level hardware setup for different boards that can run ittyOS, that all link to this directory and act as bootloaders.

the `FS/` directory contains the files i have on my microSD card which contains some images used by ittyOS. how this works will be changed later in development with automatic SD card formatting tools, but for now you can simply format your SD card for FAT and upload this filetree.
